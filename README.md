# LARRIA · Larria的3d驾照考试练习场

Three.js + TypeScript + Vite + cannon-es 的本地科目二场地驾驶体验，开放直角转弯、曲线行驶、侧方位停车和倒车入库四项考试，以及独立的自由练习。

## 启动

```sh
npm install
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173/car-drive-3d/ ，推荐桌面 Chrome / Edge 并启用硬件加速。模型与 Draco 解码器已本地化，运行时无需在线 CDN。

```sh
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:browser:all
# 单独执行（PWA 须先 npm run build）
npm run test:e2e
npm run test:settings
npm run test:pwa
# 本机已有 Chrome 时可选
PLAYWRIGHT_CHANNEL=chrome npm run test:browser:all
```

测试默认使用 Playwright Chromium；本机可通过 `PLAYWRIGHT_CHANNEL=chrome` 使用已安装的 Chrome。主套件与设置套件由 Playwright 启停 5173 开发服务器，PWA 套件启停 4178 生产 preview（必须先构建）。端口严格占用检查，不复用已有服务；请先关闭占用对应端口的服务，避免测试旧构建。手工验证现有服务时可设置 `E2E_URL=http://127.0.0.1:5173/car-drive-3d/`（PWA 必须指向生产服务），此时不托管服务器。`test:browser:all` 串行执行主浏览器、设置和 PWA 套件，任一失败即退出。

## 操作

- 默认游戏化操作（“拟真操作”关闭）：W / ↑ 前进，S / ↓ 在前进时先制动，真正停稳后继续按住自动挂 R 倒车；倒车中 W 同理刹停后挂 D 前进。W 与 S 同按仅制动。空格和触屏刹车始终纯刹车；触屏油门按当前档位驱动。
- 在设置开启“拟真操作”：W / ↑ 油门；S / ↓ / 空格纯刹车；Z / X / C 手动选档。两种模式均可手动换档，N 档及行驶换向保护保留；考试规则不随操作模式改变。
- A / ←、D / →：转向，松手回正。
- 1：车外环绕；2：驾驶位；3：跟随。
- Z → R 档，X → N 档，C → D 档；与界面按钮使用同一保护入口，不能经 N 绕过行驶方向切换保护。
- R：复位当前考试或自由练习；Esc：暂停。锁定环视时 Esc 先解锁、再次按下才暂停。
- 屏幕方向盘左右拖动；油门和刹车按钮可按住。触屏支持不同手指同时操作踏板、方向盘与座舱视角；一指离开不会松开其他指令。
- 驾驶位在场景区域移动鼠标即可转头，无需按左键；点击“锁定环视”可连续转头（需浏览器允许 Pointer Lock），拒绝时仍可悬停转头。鼠标按住或触屏单指支持上下拖动视角，不使用触屏锁定。跟随镜头支持独立上下拖拽偏移，随车移动时保留偏移，安全限幅避免翻转和钻地；回正清除偏移。运行及冻结结果均可观察。双击场景或点击“回正视角”回正；悬停 UI 不转头。切换视角、失焦或弹窗会主动解锁。
- 驾驶键长按不触发页面默认滚动；Ctrl / Cmd / Alt 组合键、表单和按钮焦点不会被驾驶键抢占。暂停后须显式继续并重新按键。
- 项目选择 → 考前说明 → 默认驾驶座舱考试 → 结果。项目首页、运行 HUD 和暂停页均可进入设置；运行中打开会先暂停，关闭后仍须显式点击“继续”。帮助、失焦和切后台同样暂停物理及判定。
- 车漆、车灯、渲染质量、车外后视镜展开及拟真操作偏好保存在浏览器本地（版本化逐字段校验，损坏/不可用存储回退内存）；车辆位置、考试状态不保存。刷新后仍从项目选择/起点开始。
- 驾驶座舱中三路后视画面嵌入模型实际镜面；车外视角保留右上辅助窗口，可点击放大或收起。
- 四项考场均可选；首次开始默认驾驶座舱，失败或成功后重试（含 R 键）继续保持自己选的自由环绕/驾驶座舱/跟随视角及其对应镜面显示。
- 自由练习为独立模式：100×100 m 场地内有四项原尺寸考场岛，直角左上 (-26,+19)、曲线右上 (+8,+19)、侧方左下 (-36,-16)、倒库右下 (+20,-22)，中央保留连通通道。岛内标线、导流线仅供练习，不加入碰撞、计时、成绩或考试判罚；可前进、刹停、倒车、换挡、暂停、复位和退出。练习与考试切换时场地、车辆和判定分别复位。

## 实现和范围

- 优先使用现成 Ferrari 458 Italia GLB，具有内饰、独立车轮、方向盘。实际模型为开放座舱运动轿跑，不是四门三厢家轿。
- 二次调整车漆与内饰材质，增加可动踏板、灯光响应、方向盘与车轮联动。
- cannon-es RaycastVehicle：重力、射线轮胎、悬架、驱动、制动、边界碰撞。为低速交互体验限制翻滚，非真实车型标定；考试采用用户给定的分项目评分：100 分起、80 分合格，非已核实的官方规范；轮胎宽度为模拟配置，非厂家数据。
- 左右与中央后视视角使用独立实时后向镜像相机；左右保留车身边缘，中央使用后窗附近视点。座舱中映射到原模型镜面的真实三角形轮廓，车外显示辅助窗口。仍为后向镜像视频，不是精确平面/凸面光学反射。
- `src/vehicle-view-profile.ts` 定义通用眼位与镜面绑定接口，`src/ferrari-view-profile.ts` 隔离当前车型的几何选择与相机配置。更换模型时提供新的 profile（实际镜面几何、UV、眼位、后视相机），无需修改 UI 与 MirrorSystem；不保证自动识别任意模型镜面。
- 四个考道与规则、道路绘制和示意图共享 `CourseDefinition` 米制定义；边线为判罚线，不是阻挡车辆的实体墙。远景建筑、树木和灯杆保留。
- 停车规则忠实模拟参考项目而非完整真实驾考规范：侧方不检查是否先驶过车位，倒库保留实际前/倒方向阶段，并在每次前进转倒车时检查两前轮均越过对应的模拟控制线；新增控制线是本项目布局，不是官方尺寸依据。入库计数与合格停稳状态分开：侧方每次考试只计一次，倒库左右倒车阶段各至多计一次；微动、朝向或整车入库条件失准会清除当前停稳合格状态，但不会靠库内抖动重复增加次数，须重新合格停稳才能继续出库。以本项目模拟实现为准，勿作为正式驾考判分依据。
- **已知限制**：侧方位停车和倒车入库已接入场地、规则与交互，但两项均未完成浏览器界面的完整真实驾驶通关验收；倒库仅曾在固定步物理搜索中走通过，不等于用户操作流程已验证。可能仍有操控可达性问题，不将其描述为已实测可通关。
- 速度是当前模拟值，不对应真实 Ferrari 性能。车内原模型仪表没有真实读数纹理，速度与档位在界面呈现。

## PWA 与更新

- 支持安装到桌面；在 HTTPS 或 localhost 的生产构建中启用 Service Worker。
- 首次在线加载并完成缓存后，可离线打开，包括车型和 Draco 解码器。缓存不等于数据永久保存，浏览器仍可能回收空间。
- 页脚提供“安装应用”和“检查更新”。后台每 15 分钟及返回页面时检查更新。
- 考试或自由练习进行中及暂停中均禁止刷新，更新不会弹模态打断驾驶；退出后必须确认才可更新。无更新、离线、安装状态显示可点击关闭的轻提示，真实更新与刷新仍用确认弹窗。iOS 使用 Safari 的“分享→添加到主屏幕”。
- `npm run build && npm run preview` 可本地检查 PWA；开发模式不注册生产 SW。
- `npx playwright test --config tests/pwa.config.mjs` 检查缓存/离线与更新保护。

## 用户给定评分规则

- 四项考试均从 100 分开始，80 分及以上合格，低于 80 分立即结束；严重错误扣 100 分。HUD 实时显示分数，轻量扣分提示不拦截操作，冻结结果列出分数与扣分原因/时间。
- 侧方行驶中车身触边扣 10 分、车轮压边扣 10 分，分别记录，同时满足扣 20 分，扣后可继续。同类连续接触一次，离开再接触重新扣分。倒车入库操作后在库位附近停稳而整车未入库扣 100 分；碰擦前后车辆仍扣 100 分。
- 倒库车身出道路或库位边界扣 100 分；每次前进转倒车前，两前轮均须越过对应模拟控制线，缺任一轮扣 100 分。
- 直角/曲线仅用轮胎判道路边线，压线扣 100 分；车身扫线不单独扣分。
- 停车验收仍须整车入库、规定朝向及次数；所有项目终点要求左右后轮完整越过有限终点线，倒库最终向前完成。原时限、方向序列、起步/停车阈值继续保留；不增加坡道项目。
- 上述为用户指定模拟判罚，不声称已核实的官方驾考标准。

## 直角规则来源与规格

参考只读项目 `car-drive/src/config/scenes/scene-0-right-angle.js`、`core/rules.js`、`core/geometry.js`、`core/collision.js` 的真实实现。

- 当前集中模拟配置：车身 4.10 × 1.72 m（不含镜），轴距 2.650 m，道宽=轴距+1 m=3.650 m；入口12 m、出口10 m，初始车身中心 (0,9)，朝 -Z。
- 判罚四条开放道路边界，不封入口；按四轮轮胎投影压线扣 100 分，车身扫线但轮胎未压线允许。终点要求左右后轮完整越过有限标线，并保留真实穿越历史，不把延长线当终点。
- 按油门锁存起步；速度 < -0.0042 m/s 判倒车；起步后未按油门且速度 < 0.021 m/s 判停车。阈值由参考 0.01/0.05 px/帧、7 mm/px、60 Hz 换算。
- 顺序：倒车 → 停车 → 边界 → 终点。没有时间限制、转向灯扣分、停车宽限或必经检查点；车轮压线规则由本次用户要求替换原车身判线。
- 60 Hz 唯一物理累积器，每个子步后判定；暂停与结果冻结，恢复不补跑。考试最高速度以各项目设置为准，默认 6 km/h；历史路线回归使用显式 17 km/h 设置，不属于默认速度通关验收。停车转向锁45°，随速度减小；未缩小车身或放宽道路。
- 练习提示：入口适当靠左，在直角处把握右转时机，转正后及时回轮。可以松油门滑行，但不得停车。
- 核心模块：`vehicle-config.ts`、`courses/right-angle.ts`、`exam-rules.ts`、`exam-session.ts`、`exam-ui.ts`。
- `tests/drive-search.test.ts` 为固定步真实物理路径回归；`tests/verify-exam.mjs` 通过UI操作生成完整行驶遥测与截图，不传送车辆。

## 曲线行驶规格与验证

- 只读参考 `car-drive/src/config/scenes/scene-1-s-curve.js` 与 `core/scene-loader.js`；实际生成方向先右后左，不沿用参考注释中相反的文字。
- 中心半径7.5 m，道宽固定3.5 m；两个反向135°弧各48等分，合并97点，沿首末采样弦延伸入口2 m/出口3 m。两侧各99点，196条开放边界，不封入口和出口。
- 起始中心(0,9.5)、朝-Z；第一圆心(7.5,8)，第二圆心由接点全精度反射计算。两边在接缝交换内外半径5.75/9.25 m。
- 固定终点(23.8566,-5.6066)→(27.3566,-5.6066)独立于弦向延伸末端，保留参考微小偏差。沿用直角轮胎压线、倒退/停车阈值与失败优先级；后轮越过有限终点才完成，无额外检查点。
- 世界仅替换课程Group并释放其独占几何/材质/纹理，环境和车辆保持；边线按实际长度及方向绘制，不使用包围盒填充斜线。
- `node tests/verify-s-curve.mjs` 持续按W并拖屏幕方向盘完整通过，读取遥测但不写车辆位姿/结果。`artifacts/s-drive-track.json` 和 `s-{projects,briefing,cockpit,turn,driven-result}.png` 保存轨迹与画面；直角对应 `exam-drive-track.json`。
- `npm run test:e2e` 覆盖四课程进入、失败、冻结、重试保留视角、交叉切换、镜面、锁定环视、多指触控及390px窄屏；直角自动驾驶路线贴近边界，浏览器帧调度下仍可能有低概率波动。PWA测试覆盖生产离线重开与考试中禁止自动更新；首次缓存仍须在线。

### 项目最高速度与重新开始

驾驶设置中各项目独立保存最高速度（km/h）：直角转弯、曲线行驶、侧方位停车、倒车入库四项均默认 6，考试可设 3–20；自由练习默认 15、可设 3–60。旧版偏好缺少字段时使用默认值，所有低于 3 的已存速度迁移至 3，其他合法旧偏好（包括原先保存的倒库 3 km/h）保留，不强制覆盖为新默认。设置即时生效并自动持久化，无需保存按钮；弹窗头部与关闭按钮始终位于滚动内容外。物理引擎正反向限制驱动力，超速或调低设置后先制动，不按帧强改速度。停车考试仍为 30 秒；可在设置中自行提高速度，时限未改。

R 可重新开始当前项目，运行、暂停和成绩查看均支持；输入控件及打开的弹窗不响应。跟随视角上下拖动与自由环绕方向一致。侧方车身触边/车轮压线的 10 分扣分保留，但前进时车头或倒车时车尾越出道路与停车库并集的外边界即直接不合格；使用沿行驶方向的车身前/后边缘，不等同于前轮越线，库口不作为外边界。未完成要求入库次数时，前轮前行跨越有限终点即失败，正常通关仍要求后轮完全通过。
